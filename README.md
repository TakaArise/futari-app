# ふたりのキョリ

気になる人・恋人と2人で遊ぶ「距離が縮まる罰ゲーム」アプリ。
`index.html` 1ファイルだけ。インストール不要、通信も不要、オフラインで動く。

---

## 使い方（3ステップ）

1. `index.html` をスマホに送る（AirDrop / LINEで自分に送る / Googleドライブ）
2. Safari や Chrome で開く
3. Safari → 共有ボタン → **「ホーム画面に追加」** でアプリのように全画面起動

※ 2人でスマホ1台を回して使う想定。データは端末内（localStorage）にだけ保存され、外には一切送信されない。

---

## 5つの画面

| 画面 | 中身 |
|------|------|
| 🎯 ルーレット | 円盤が回って罰ゲームを決定。タップで回転、カチカチ音つき |
| 🃏 カード | 伏せたカードから直感で1枚。めくると罰ゲームが出る |
| 📜 ルール | 「〇〇したら罰ゲーム」の発動条件。20個のプリセット＋自由追加 |
| 💬 質問 | 距離が縮まる質問50問。答えられなかったら罰ゲームへ直行できる |
| ⚙️ 設定 | オリジナル罰ゲーム追加／履歴／効果音・バイブ切替 |

---

## レベル設計（ここが肝）

いきなり距離を詰めると引かれる。段階を選べるようにしてある。
チップで複数選択でき、選んだレベルだけが抽選対象になる。

| Lv | 名前 | ねらい | 例 |
|----|------|--------|-----|
| **Lv1** | ふれあい | 触れる口実をつくる。初対面〜気になる段階 | 30秒手をつなぐ／目を10秒見つめる／顔を20cm以内に近づける |
| **Lv2** | きゅん | 恋人未満の距離を一気に詰める | 恋人つなぎ30秒／おでこをくっつけて10秒／耳元で「好き」 |
| **Lv3** | ドキドキ | 付き合ってから、または勝負どころ | 顔の距離5cmで10秒／ほっぺにキス／本音をひとつ告白 |

- 収録数：**罰ゲーム94個**（Lv1×30 / Lv2×34 / Lv3×30）＋ 自作分
- 「30秒」「1分」など時間が入った罰ゲームは、結果画面に**カウントダウンタイマー**が自動で出る（残り3秒から音が鳴る）

## 出す罰ゲームを自分で選ぶ

ルーレット画面・カード画面・設定画面の **「🗂 一覧から自分で選ぶ」** から、94個すべてを一覧で見て1つずつ設定できる。
各項目に **［− 枠数 ＋］** がついていて、0〜6の範囲で「何枠ぶん入れるか」を決められる。レベルごとの **全ON / 全OFF** も一括でできる。

| 枠数 | 意味 |
|---|---|
| 0 | 使わない（抽選に出ない） |
| 1 | ふつうに1つぶん入る |
| 2以上 | **その数だけ枠を占める＝その分だけ当たりやすい**（行が金色＋数字表示） |

**同じ罰ゲームを何回でも入れられる**

たとえば「ほっぺにキス」を5、「30秒間ハグしたまま動かない」を1、他をすべて0にすると、
ルーレットは**6分割のうち5枠がキス**、カードも**6枚中5枚がキス**になる。ほぼ確実に当たるけれど、1/6でハグに逃げられる緊張感が作れる。

**おまかせと指名、どちらもできる**

| 合計枠数 | 動き |
|---|---|
| 7枠以上 | 毎回ランダムで6つ選ばれる（「別の6つに入れ替える」でシャッフル） |
| ちょうど6枠 | **その6枠がそのまま並ぶ**＝完全に自分の指定どおり |
| 2〜5枠 | その数だけ円盤を分割。2択・3択の勝負にもできる |

行そのものをタップすれば 0⇔1 の切替なので、「やりたくないものを消す」だけならタップ1回で済む。

## 盛り上がる遊び方

**基本ルール**
ルール画面で3〜4個ONにする → 会話スタート → 破った方がルーレットかカードを引く

**ルールの選び方**
- 会話が固いとき → 「敬語を使ったら」「相手の名前を呼ばずに話しかけたら」
- 相手が受け身なとき → 「質問に質問で返したら」「「別に」「普通」で答えたら」
- 距離が開いてきたとき → 「10分間まったく相手に触れなかったら」
- 飲みの席 → 「相手より先に飲みものを飲み終えたら」

**おすすめの流れ**
1. まずLv1だけONにして5分ほど回す（触れることに慣れる）
2. 場が温まったらLv2を追加
3. Lv3は「今日はここまでやる？」と相手に聞いてからONにする

**質問ゲーム連動**
質問画面で交互に引く → 答えられない／はぐらかしたら「答えられなかった → 罰ゲーム」ボタン

**追加ルール案**
- 拒否権は1ゲームにつき1回まで
- 拒否したらレベルが1つ上がる
- 同じ罰ゲームが2回出たら時間が倍

---

## カスタマイズ

- **ルール追加**：ルール画面下の入力欄（2人の口ぐせを入れると一気に盛り上がる）
- **罰ゲーム追加**：設定画面でレベルを選んで追加
- 追加分はルーレット・カード両方の抽選に混ざる

---

## 技術メモ

- 単一HTML / Vanilla JS / 外部ライブラリ・API通信ゼロ
- ルーレットはCanvas描画（イージング付き回転＋当選判定は上部ピン基準）
- 効果音はWebAudio、振動は Vibration API（設定でOFF可）
- 保存先：localStorage キー `futari_kyori_v1`
- 「初期状態に戻す」で全消去
